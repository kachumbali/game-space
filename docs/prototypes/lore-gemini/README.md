# Gemini lore proposals (raw, 2026-10-22)

Unmodified lore text produced with the Google Gemini code tools for this project,
as supplied by the owner. Kept for provenance.

**Status: adopted in adapted form.** The adapted, canon-consistent versions live in
`docs/LORE_HISTORY.md`, `docs/LORE_FACTIONS.md` and `docs/LORE_FROGG.md`. Where the
raw proposals collide with the game's established canon, the canon wins:

- The **Halberd** is a 128 m human corvette in the game. The raw proposal's
  18 m two-seat heavy fighter of that name became the **Falchion**.
- The jump-drive threshold is stated as 500 m in the raw text; the game's Exeter
  frigate is 450 m and jumps, so the rule is adapted to "frigate-class and up".
- The proposal's human corvette names (Watchkeeper, Vanguard-C) do not exist;
  the Halberd is the human corvette class.
