# Ship and weapon database

`ships.csv` (one row per hull) and `weapons.csv` (one row per weapon) are generated from the current build,
which embeds `data/db.json` through `src/16_db.js`. They are derived views, not a source of truth; never edit
them by hand. Regenerate with `python3 tools/export_db.py`.

Units: metres, seconds, radians; `dps` = nominal damage per second before shields, armour and misses (damage / cooldown),
`range_m` = speed x lifetime for projectiles (theoretical; the AI engages at 55 % of it). `armor_thresh_*` are per-hit
thresholds: effective threshold = base x class multiplier. `mass_class` is the crash-damage mass. Derived columns are
computed in the exporter, everything else is the raw definition value.

Source of the numbers: `data/db.json` plus runtime-derived values in the build. The values are design parameters,
not measurements of anything real. Renders: `docs/img/ships/<id>_{34,top,side,front}.png`; faction contact
sheets are generated by `python3 tools/render_pack.py` under `docs/img/ships/contact_sheets/`.
