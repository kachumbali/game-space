# Intro test animation: spec for assets (Gemini) and player (Claude)

Goal: a 30-40 s WC2-style test cutscene, `?scene=intro_test`, to prove the pipeline: pixel-art talking heads (blinking eyes, mouth shapes driven by the text), a scaled-sprite space shot, a room background, a typewriter text box, timed events. Text only, no voice (owner constraint, `docs/CUTSCENES.md`). The player (engine) is built by Claude in `src/81_scene.js`; assets and scene data are made by Gemini. Both sides code to THIS file format.

## 1. Folder layout (Gemini creates; the build bundles it into the single index.html)
```
assets/scenes/intro_test/
  scene.json            timeline (section 3)
  bg_space.png          320x200  star field + planet limb
  bg_briefing.png       320x200  carrier briefing room, riveted teal/slate walls, amber lights
  ship_kestrel.png      96x48    side/three-quarter view of the fighter, transparent background
  ship_halberd.png      160x56   corvette, same style
  heads/<id>/           one folder per character (section 2): base.png, eyes_*.png, mouth_*.png, head.json
  ui_frame.png          optional 320x200 overlay frame (HUD edge), transparent
tools/make_atlas.py     optional helper: checks sizes/palette and prints a report (Gemini may write it)
```
All art: PNG, indexed or RGBA, **<= 32 colours per image**, no anti-aliasing, hard pixel edges, shared palette across the folder (teal/slate steel, amber warning lights, off-white, one skin ramp per character). Logical canvas is 320x200; the player scales it by an integer factor and keeps the pixels crisp.

## 2. Talking heads
- Size **64x64** per head. `base.png`: head and shoulders, **no eyes and no mouth drawn** (flat skin where they go), plus hair, collar, insignia.
- Overlays, each the same 64x64 with transparent background except the feature: `eyes_open.png`, `eyes_half.png`, `eyes_closed.png`; mouth shapes `mouth_rest.png`, `mouth_A.png` (open wide), `mouth_E.png` (wide, teeth), `mouth_O.png` (round), `mouth_MB.png` (closed, pressed), `mouth_FV.png` (lower lip under teeth). Optional `brow_*.png`.
- `head.json`: `{ "name": "CDR. IMANI", "size": [64,64], "eyes": {"open":"eyes_open.png","half":"eyes_half.png","closed":"eyes_closed.png"}, "mouth": {"rest":"mouth_rest.png","A":"mouth_A.png","E":"mouth_E.png","O":"mouth_O.png","MB":"mouth_MB.png","FV":"mouth_FV.png"}, "blink": {"min":2.0,"max":5.0}, "voiceBlip": 220 }`. Offsets are baked into the overlays (same canvas), so no coordinates are needed.
- Characters for the test (names are fictional placeholders): **CDR. IMANI** (carrier commander, older, calm), **HAWK** (Lt. Maya Okafor, flight lead, dry humour), **MEOW** (Lt. Tom Cat, the player, tongue in cheek; can be helmet-on, one eyes/mouth set). Style guide for faces: `docs/CUTSCENE_ART_PROMPTS.md` section 0 (style A, the VGA painted look) and the consistency workflow in its section 1.
- Lip-sync is generated by the player from the text (vowel and consonant classes to A/E/O/MB/FV/rest, about 12 mouth changes per second while the typewriter runs, rest when it ends). Gemini does not need to time mouths; an explicit `"mouth"` cue in the scene overrides it.

## 3. scene.json (timeline)
```json
{
  "id": "intro_test", "size": [320, 200], "music": null,
  "events": [
    {"t": 0.0,  "do": "bg",     "img": "bg_space.png", "fade": 0.8},
    {"t": 0.5,  "do": "title",  "text": "CLAUDE SPACE COMMANDER", "sub": "TEST SEQUENCE", "dur": 3.0},
    {"t": 4.0,  "do": "sprite", "id": "k1", "img": "ship_kestrel.png", "from": {"x": 40,  "y": 120, "scale": 0.3}, "to": {"x": 230, "y": 80, "scale": 1.6}, "dur": 4.0, "ease": "in"},
    {"t": 4.0,  "do": "sprite", "id": "h1", "img": "ship_halberd.png", "from": {"x": 260, "y": 40,  "scale": 0.5}, "to": {"x": 90,  "y": 60, "scale": 0.9}, "dur": 6.0, "ease": "inout"},
    {"t": 10.0, "do": "bg",     "img": "bg_briefing.png", "cut": "static"},
    {"t": 10.2, "do": "head",   "id": "imani", "char": "imani", "pos": "left"},
    {"t": 10.5, "do": "say",    "who": "imani", "text": "Eagle flight, this is not a drill. Unknown contacts at the Lily relay.", "cps": 28},
    {"t": 16.0, "do": "head",   "id": "hawk",  "char": "hawk", "pos": "right"},
    {"t": 16.2, "do": "say",    "who": "hawk",  "text": "Unknown how, Commander?", "cps": 28},
    {"t": 19.0, "do": "say",    "who": "imani", "text": "They are not answering our hails.", "cps": 28},
    {"t": 23.0, "do": "say",    "who": "meow",  "text": "Then we go and say hello.", "cps": 28, "mouth": null},
    {"t": 27.0, "do": "bg",     "img": "bg_space.png", "cut": "static"},
    {"t": 28.0, "do": "end"}
  ]
}
```
- `do` values: `bg` (cut: `static` noise burst, or fade), `title`, `sprite` (position in canvas pixels, centre anchored; `scale` interpolates, **nearest-neighbour**), `head` (pos left|right|center; removes any head at that pos), `say` (typewriter in the text box under the speaker; `cps` characters per second; the box waits `max(1.2, len/cps + 0.8)`), `shake`, `flash`, `sfx` (synth names from `src/12_audio.js`: click, pickup, ...), `music` (hook only), `end`.
- Times in seconds from scene start; the player drives everything from one clock, so skipping (any key / tap, SPACE advances to the next line) is easy.

## 4. Acceptance (what "done" means)
Gemini: all files present, sizes exact, <= 32 colours each (the helper script reports it), head overlays align (a test sheet PNG with every mouth over the base), `scene.json` parses, no real person names or emails (`python3 tools/check_opsec.py`). Claude: `src/81_scene.js` plays it headless (`tools/tests/scene_t.py`: loads `?scene=intro_test`, steps the clock, asserts events fire, mouth changes while text types, no console errors, screenshots at 2 s, 12 s, 20 s), skip works, phone layout 844x390 fits. Nothing here is hand-judged for beauty until someone looks at the screenshots.

## 5. If Gemini cannot make pixel art directly
Allowed fallbacks, in order: (a) its image generation, then a Python step (Pillow) to downscale with nearest neighbour, quantise to 32 colours and slice the overlays; (b) draw procedurally with Pillow (rectangles and dithering are enough for a test: a flat skin head, simple eyes and mouths); (c) leave placeholders (solid-colour shapes with the right sizes) and Claude draws the first real set. A working pipeline with ugly art beats pretty art that does not load.
